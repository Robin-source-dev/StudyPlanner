About Student Study Planner

A simple web application that helps student organize their assignments, study schedules, and academic tasks in one place.

Project Overview

The Student Study Planner is a web-based application designed to help students manage their academic workload. It allows users to add, edit, delete and organize study tasks while storing the information in the browser's local storage. The application promotes better time management and helps students avoid missing important deadlines.

Problem Statement

Many students struggle to keep track of assignments, project deadlines, exams and study schedules leading to poor time management and missed deadlines. This application provides a simple solution by allowing users to organize and monitor their academic tasks from one convenient dashboard.

Key Features

📝 Task Management

Add, edit, delete and organize assignments, projects, exams and study sessions.

Local Storage

Tasks are saved in the browser using local Storage, allowing users to access their information whenever they revisit the application.

📊 Dashboard

View task statistics, pending work, completed assignments and upcoming deadlines.

🔍 Search & Filter

Quickly find tasks by searching or filtering according to priority.

Technologies Used

  • HTML5 for page structure
  • CSS for responsive design and styling
  • Javascript (ES6) for interactivity
  • Local Storage API for data persistence
  • Flexbox and CSS Grid for layouts
